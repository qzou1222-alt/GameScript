# GameScript

VS Code support for the GS programming language.

## What's GS?

GS (GameScript) is a programming language to make simple games.

## Features

- Syntax highlighting
- Code completion
- Hover information
- Diagnostics
- Bracket validation
- GameScript Run command
- `.gs` and `.gamescript` file support

## File Extensions

GameScript supports:

- `.gs`
- `.gamescript`

## Requirements

GameScript requires Python 3.12 or newer.

## Running GameScript

Open a `.gs` or `.gamescript` file and use:

**GameScript: Run**

to execute the file.
